# Archivo Familiar v4.2.0-alpha1

## EP-004.1 — Nuevo motor del árbol

Primera fase de la v4.2.0. El árbol mantiene su diseño actual, pero deja de
recalcular relaciones recorriendo toda la base de datos en cada operación.

### Cambios internos
- Índices de padres, hijos y cónyuges.
- Nuevo modelo como fuente principal.
- Hermanos calculados desde progenitores compartidos.
- Eliminación de helpers duplicados.
- Compatibilidad de lectura con datos heredados.
